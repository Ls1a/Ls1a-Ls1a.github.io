菲区渠道怎么用

不用自己碰菲律宾 IP 和外卡 · 买现成卡 / 直充

方式一：菲区卡充（卡密自兑）

适合 ChatGPT Plus。在 16688 下单后店家给一串卡密 + 兑换链接，卡密一般可囤 1 周。

  1. 先按下方「接单预检」确认买家账号是 Free、不在 Team 里；
  2. 在 16688 搜「Plus 菲区卡充」下单，支付宝 / 微信付款；
  3. 把卡密和兑换链接发给买家，买家按页面引导自己兑换；
  4. 让买家到 ChatGPT「设置 → 订阅」确认显示 Plus，截图回传再确认收货。

方式二：菲区直充（店家充到号上）

适合 Pro 100 / Pro 200，差价主要靠这个赚。

  1. 买家在闲鱼下单后，你去 16688 下一单菲区直充；
  2. 下单时只填买家的 ChatGPT 账号邮箱，正规直充不需要密码；
  3. 店家用菲律宾区价格扣费开通，充好后通知你；
  4. 让买家在「设置 → 订阅」核对显示 Pro，再交付确认。

差价从哪来（2026-11 核实数字）

菲律宾区官方价：Plus ₱1,100/月（含 12% 税），Pro 200 ₱8,919.64/月，按 11 月汇率折合约 ¥931；美区 Pro 200 是 $200，折合约 ¥1,336，差 ¥400 多。店家菲区稳渠道做到 Pro 100 ¥755.20、Pro 200 ¥1,212，你卖 ¥850 / ¥1,300，每单约 ¥90–95 毛利。

Plus 别死磕菲区：16688 官网正价直充 ¥132.23 反而比菲区卡充 ¥134.81 便宜，竑予 ¥120.5 更低。Plus 走官网直充，Pro 走菲区直充。

进阶：自己动手充菲区（不用店家时）

  1. 备菲律宾 IP，全程全局模式，住宅 IP 更稳，机房 IP 容易被风控拦；
  2. 无痕模式打开 chatgpt.com，确认价格显示 ₱1,100 而不是美元；
  3. 账号必须是没用美元付过费的 Free 号，否则币种锁死改不过来；
  4. 付款用海外卡（国内卡网页端直接拒付），账单地址国家选美国、填免税州（如 Oregon, Portland 97201），税归零后 Plus 实付 ₱982.14，约 ¥106；
  5. Pro 200 同样操作应显示 ₱8,919.64，确认价格无误再点订阅；续费按月从这张卡自动扣，续费前以页面价为准。

接单前预检清单

收款前先问完这四件事 · 省掉绝大多数售后
  • 账号现在是 Free 吗？让买家打开 chatgpt.com → 左下角头像 → 设置 → 订阅。显示 Free 才能充卡充 / 多数直充；显示 Plus / Pro 和到期日，要先取消自动续费、等刷回 Free。
  • 账号在 Team 空间里吗？设置 → 工作区 / 团队里有 Team 名字就是在团队里，个人卡充不进去，要先退出 Team 或换个人号。
  • 号是自己注册的，还是买来的成品号？以前用过低价卡吗？买来的号、用过 0 元购 / 黑充 / 低价 CDK 的号属于风险号：可以接，但先把质保说清 —— 只保订阅本身，掉订阅按未用天数比例退，封号 / 风控不保。
  • 以前用美元付过费吗？让买家看设置 → 账单记录：用美元付过费的号币种会被锁死，走不了菲区价；有 $0 订单或欠费账单的，也先如实告诉你再定渠道。

完整操作流程

从准备到售后 · 照着走就能开张
1

备齐账号、软件和启动资金（约 ¥600）

  • 闲鱼账号（实名、绑定支付宝收款）、微信 / 支付宝各留一个能正常收款的号；
  • 进货账号：16688、链动小铺先注册好，OKAI66、EzSub、UpPlusPro、小小AI 收藏下单页；
  • 启动资金约 ¥600：先垫进货款 + 留一笔售后备用金，掉订阅按天退款时不用临时凑钱；
  • 建一个简单表格记账：日期、品类、买家、进货价、卖价、渠道、到期日，售后查单全靠它。
2

先小额试单，把全流程跑通一遍

  • 在 16688 用最小金额买一张 Plus 菲区卡充（¥134.81）或官网直充（¥132.23），充到自己账号上；
  • 完整走一遍：下单 → 拿卡密 → 兑换 → 设置里确认 Plus → 截图留底；
  • 试单没跑通之前不要上架接单，买家的问题你答不上来最伤口碑。
3

按三条规矩定价

  • 每单赚 ¥20–100，不打价格战到底；
  • ChatGPT 跟国内市场价：Plus ¥168、Pro 100 ¥850、Pro 200 ¥1,300，不轻易破价；
  • Claude 多赚一点：Pro ¥249、Max 5x ¥999；Gemini、多邻国、X 按进货价 +¥20–100 定，见比价表。
4

闲鱼上架

  • 标题写清品类 + 档位 + 卖点，如「ChatGPT Plus 代充 月卡 充自己号 不要密码 秒到账」；
  • 详情里必须提前写清质保：只保订阅本身，掉订阅按未用天数比例退；封号 / 风控不保；风险号可接、下单即视为接受此条款；
  • 详情里放预检提醒：下单前先确认账号是 Free、不在 Team 里，省得拍下后充不进去来回扯。
5

接单与交付

  • 收款前先走一遍上方「接单预检」四问，确认能充再收钱；
  • 卡充类：把卡密 + 兑换链接发给买家，盯着他兑换完；直充类：只收买家邮箱下单，永远不问买家要密码；
  • 让买家到对应 App 的「设置 → 订阅」确认档位和到期日，截图回传，你再点发货、请他确认收货。
6

售后与避坑

  • 掉订阅：先分清是渠道问题（按未用天数比例退）还是账号被封（不保），回复话术见上方风险卡；
  • X 只卖月卡，不卖年卡，周期越长售后越不可控；
  • 多邻国自己开家庭组当组长，座位和到期日自己可控，别买来路不明的现成组；
  • 进货价每天都可能变，接到大单（Pro 200、Max）先去渠道页核实时价再报价。
